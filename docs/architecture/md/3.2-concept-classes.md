## 3.2 Conceptual Classes

### 3.2.1 Creation of Conceptual Classes
The table below shows conceptual classes determined by generic class categories and examples from the Classifi-Cam system, updated to reflect the actual design and the classes in the domain model.

<div style="display: flex; justify-content: center;"><div style="max-width:85%; font-size: 0.7em; line-height:1.2">

| **Conceptual Class Category**                                                  | **Example from Classifi-Cam System**                                                                                                              |
| ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Business transactions                                                          | ClassificationSession - Represents a user session for image classification                                                                          |
| Transaction line items                                                         | Detection - Contains results for a single image, including detected objects and labels                                                              |
| Product or service related to transaction                                      | ClassificationModel - An ONNX model used for object detection and classification                                                                   |
| Where transaction is recorded                                                  | Images - Stores image filename and base64 data                                                                                                      |
| Roles of people or organizations related to transaction or actors in use cases | ExternalAPI - Provides matches and details for classified objects                                                                                   |
| Place of transaction; place of service                                         | HomeView - Main entry point for user interaction                                                                                                    |
|                                                                                | LibraryView - Displays user's image library                                                                                                         |
|                                                                                | SettingsView - Interface for managing models, preferences, and thresholds                                                                          |
|                                                                                | MatchesView - Displays matches for classified objects                                                                                               |
|                                                                                | DetailsView - Shows detailed information for a selected match                                                                                       |
|                                                                                | ResultsView - Displays classification results                                                                                                       |
|                                                                                | FavoritesView - Displays user's favorite items                                                                                                      |
|                                                                                | RecentsView - Displays recently viewed items                                                                                                        |
|                                                                                | CameraView - Captures new images                                                                                                                    |
| Noteworthy events, often with a time or place we need to remember              | Timing - Tracks timing statistics for inference and processing                                                                                      |
| Physical objects                                                               | Images - The photo or image being classified                                                                                                        |
| Descriptions of things                                                         | Detection - The detected object and its properties                                                                                                  |
| Catalogs                                                                       | Models - List of available classification models                                                                                                    |
| Containers of things (physical or information)                                 | RecentMeal - Container for recently viewed meals                                                                                                    |
| Things in a container                                                          | Meal - An item with detailed information (e.g., recipe, category, etc.)                                                                            |
| Rules and policies                                                             | AppSlice, APISlice - Application and API state management                                                                                          |

</div></div>
