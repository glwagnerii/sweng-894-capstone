## 3.4 System Contracts for Input Operations (Classifi-Cam)

Listed below are the system input contracts for the primary input operations of the Classifi-Cam application.

<div style="display: flex; justify-content: center;"><div style="max-width:85%; font-size: 0.7em; line-height:1.2">

| Name: | <div style="width:500px;">**captureImage**()</div> |
|:---|:---|
| Responsibilities: | Capture an image using the device camera |
| Type: | CameraView method |
| Cross Reference: | Camera View use case |
| Exceptions: | - Camera not accessible <br>- Permission denied |
| Pre-conditions: | - Camera device available <br>- Permissions granted |
| Post-conditions: | - Image captured <br>- Image stored in app state |
| Notes: | - Supports multiple camera devices <br>- Can preview before capture |

</div></div>

<div style="display: flex; justify-content: center;"><div style="max-width:85%; font-size: 0.7em; line-height:1.2">

| Name: | <div style="width:500px;">**selectImage**(source)</div> |
|:---|:---|
| Responsibilities: | Select an image from device library or cloud storage |
| Type: | LibraryView method |
| Cross Reference: | Library View use case |
| Exceptions: | - Invalid image format <br>- Source not accessible |
| Pre-conditions: | - Image source configured |
| Post-conditions: | - Image loaded <br>- Image available for inference |
| Notes: | - Supports local and cloud sources <br>- Can preview before selection |

</div></div>

<div style="display: flex; justify-content: center;"><div style="max-width:85%; font-size: 0.7em; line-height:1.2">

| Name: | <div style="width:500px;">**loadModel**(modelFile)</div> |
|:---|:---|
| Responsibilities: | Load and validate a classification model (ONNX) |
| Type: | SettingsView/ModelManager method |
| Cross Reference: | Settings View use case |
| Exceptions: | - Invalid model format <br>- Model file not accessible |
| Pre-conditions: | - Model file available |
| Post-conditions: | - Model loaded <br>- Model validation status updated |
| Notes: | - Supports multiple models <br>- Model metadata displayed |

</div></div>

<div style="display: flex; justify-content: center;"><div style="max-width:85%; font-size: 0.7em; line-height:1.2">

| Name: | <div style="width:500px;">**inferImage**(image, model)</div> |
|:---|:---|
| Responsibilities: | Run inference on an image using the selected model |
| Type: | Rust backend (model.rs) method |
| Cross Reference: | Results View use case |
| Exceptions: | - Model not loaded <br>- Image not available |
| Pre-conditions: | - Image loaded <br>- Model loaded |
| Post-conditions: | - Detections generated <br>- Results stored in app state |
| Notes: | - Returns bounding boxes, classes, confidence <br>- Timing stats available |

</div></div>

<div style="display: flex; justify-content: center;"><div style="max-width:85%; font-size: 0.7em; line-height:1.2">

| Name: | <div style="width:500px;">**reviewDetections**(detections)</div> |
|:---|:---|
| Responsibilities: | Review and select detected objects/classes |
| Type: | ResultsView method |
| Cross Reference: | Results View use case |
| Exceptions: | - No detections available |
| Pre-conditions: | - Detections generated |
| Post-conditions: | - Selected detection stored <br>- Ready for match fetch |
| Notes: | - Supports multiple selections <br>- Can filter by confidence |

</div></div>

<div style="display: flex; justify-content: center;"><div style="max-width:85%; font-size: 0.7em; line-height:1.2">

| Name: | <div style="width:500px;">**fetchMatches**(classLabel)</div> |
|:---|:---|
| Responsibilities: | Fetch matches (e.g., recipes) for a selected class/object via external API |
| Type: | MatchesView method |
| Cross Reference: | Matches View use case |
| Exceptions: | - API not accessible <br>- No matches found |
| Pre-conditions: | - Class label selected |
| Post-conditions: | - Matches retrieved <br>- Matches displayed |
| Notes: | - Supports external APIs <br>- Can cache results |

</div></div>

<div style="display: flex; justify-content: center;"><div style="max-width:85%; font-size: 0.7em; line-height:1.2">

| Name: | <div style="width:500px;">**fetchDetails**(matchId)</div> |
|:---|:---|
| Responsibilities: | Fetch detailed information for a selected match (e.g., recipe details) via external API |
| Type: | DetailsView method |
| Cross Reference: | Details View use case |
| Exceptions: | - API not accessible <br>- Details not found |
| Pre-conditions: | - Match selected |
| Post-conditions: | - Details retrieved <br>- Details displayed |
| Notes: | - Returns instructions, ingredients, media links <br>- Can cache details |

</div></div>

<div style="display: flex; justify-content: center;"><div style="max-width:85%; font-size: 0.7em; line-height:1.2">

| Name: | <div style="width:500px;">**updateSettings**(settings)</div> |
|:---|:---|
| Responsibilities: | Update app or model settings (thresholds, preferences) |
| Type: | SettingsView method |
| Cross Reference: | Settings View use case |
| Exceptions: | - Invalid settings format |
| Pre-conditions: | - Settings available |
| Post-conditions: | - Settings updated <br>- App state refreshed |
| Notes: | - Supports model and app settings <br>- Validation performed |

</div></div>

<div style="display: flex; justify-content: center;"><div style="max-width:85%; font-size: 0.7em; line-height:1.2">

| Name: | <div style="width:500px;">**exportResults**(format, destination)</div> |
|:---|:---|
| Responsibilities: | Export classification results (JSON, CSV) |
| Type: | ResultsView/ExportManager method |
| Cross Reference: | Results View use case |
| Exceptions: | - Invalid export format <br>- Destination not accessible |
| Pre-conditions: | - Results available |
| Post-conditions: | - Results exported <br>- Export log updated |
| Notes: | - Supports multiple formats <br>- Can export to cloud or local |

</div></div>

<div style="display: flex; justify-content: center;"><div style="max-width:85%; font-size: 0.7em; line-height:1.2">

| Name: | <div style="width:500px;">**syncData**(cloudService)</div> |
|:---|:---|
| Responsibilities: | Sync images and results with cloud storage |
| Type: | SyncManager method |
| Cross Reference: | Library View use case |
| Exceptions: | - Cloud service not accessible <br>- Sync failed |
| Pre-conditions: | - Cloud service configured |
| Post-conditions: | - Data synced <br>- Sync status updated |
| Notes: | - Supports Google Drive, iCloud, etc. <br>- Can schedule syncs |

</div></div>
